REACT & JS FOG SURVIVAL — v6

1. Install Node.js 22 or newer from https://nodejs.org.
2. Open a terminal in the folder containing package.json.
3. Run: npm install
4. Run: npm run dev
5. Open the address Vite prints, usually http://localhost:5173.

Repair 16 learning generators to power the Exit Gates.
Each generator has a visual Field Drill and an editable Repair Blueprint.
Finish the drill, repair the code, then pass its Skill Check.

Press Space or Hit to stop the needle in the marked sector.
Use Assist for an untimed check with the same repair credit.
A missed check never deletes your work.

SFX are optional and off by default. English/Nepali narration uses your
browser's installed voices; transcripts work even without a matching voice.

Your old v5 work remains saved separately. The new trial starts fresh.
Code drafts and generator repairs persist in this browser on this device.
No account, backend, live game connection, or publishing is required.

Keep the terminal running while learning. Ctrl+C stops it.
