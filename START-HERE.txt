REACT & JS DEEP DIVE — v5

1. Install Node.js 22 or newer from https://nodejs.org.
2. Open a terminal in the folder containing package.json.
3. Run: npm install
4. Run: npm run dev
5. Open the address printed by Vite, usually http://localhost:5173.

Each of the 16 cards has an Explore task and a Code task.
Follow the task, then use Next. Arrow keys work outside form controls.
The code editor and its live React preview run locally.

Play/Pause/Replay narrates in English or Nepali using your browser's voices.
If no Nepali voice is installed, you can still read the Nepali script.
Use "I'm confused" for progressive hints.

Progress, code drafts, narration preferences, and your old map-lab work
are saved in this browser. No account or cloud publishing is needed.

Keep the terminal running while learning. Ctrl+C stops it.
